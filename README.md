# 🌐 Personal Portfolio Landing Page

A modern, responsive personal portfolio landing page crafted using pure HTML5 and CSS3. This project showcases modern web design fundamentals,
custom keyframe animations, smooth button interactions, and responsive UI structure.
---

## ✨ Key Features

* Custom Keyframe Animations: Smooth entrance animations for text elements, logo, and social links using CSS `@keyframes`[cite: 3].
* Interactive Navigation: Hover effects on navigation links and action buttons with smooth color transitions[cite: 3].
* Modern Color Palette: Dark-themed UI with accent neon blue colors (`#00abf0` and `#081b29`) for a professional tech look[cite: 3].
* Social Links Integration: Integrated icons powered by Boxicons.
* Clean Code Structure: Modular HTML markup paired with organized CSS styles[cite: 3, 4].
---

## 🛠️ Built With

* HTML5: Semantic structure[cite: 4]
* CSS3: Flexbox, custom keyframe animations, CSS variables, and transitions[cite: 3]
* Typography: Google Fonts ('Poppins')[cite: 3]
* Icons: Boxicons Library[cite: 4]
